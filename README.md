# Good-Ice-Cream
Good Ice Cream
Não tem história
O Objetivo é pegar todas as frutas até o tempo acabar.
O jogador ele move para frente, trás, esquerda e direita, menos lateralmente, e ele pode criar blocos de gelo na sua frente
tem paredes como obstáculos e inimigos que perseguem o jogador, e patrulham uma área se o jogador não estiver a vista.
Sem coletáveis
Você ganha se conseguir coletar todas as frutas
Perde se acabar o tempo ou algum inimigo te encostar
o estilo de arte é pixel art, em referência ao Bad Ice Cream
