# Ice Cream Maze (Godot 4.3+)

1. Abra o Godot 4.3 ou mais novo → **Import** → selecione `project.godot` → **Run (F5)**.
2. Controles: setas ou WASD movem, **Espaço** cria/destrói gelo, **R** reinicia.
3. O mapa fica na constante `MAP` de `scripts/level.gd` (legenda no comentário acima dela).
4. Os sprites em `art/` são placeholders originais de 32x32. Para usar outra arte, substitua os PNGs mantendo os nomes
   (ou ajuste `TILE_SIZE` em `level.gd` se o tamanho do tile mudar).
